## 平台简介

OA协同办公平台是一套面向企业内部的办公自动化（Office Automation，OA）系统。OA 的核心价值在于**流程驱动与协同办公**：员工通过统一工作台处理待办审批、发起各类申请，围绕会议、日程、公告、通讯录等场景完成日常协作，管理者通过流程引擎掌握事项流转与执行情况。

平台围绕"员工日常办公"组织功能：

* **工作台**：登录即见——我的待办、今日日程、最新公告、快捷入口（发起申请/我的待办/会议日程/通讯录）。
* **流程审批**：请假、报销、出差、用章等申请，支持发起表单、审批列表、流程时间线展示。
* **协同场景**：会议日程（月历+当日日程）、组织通讯录、通知公告。
* **后台管理**：用户、部门、岗位、角色、菜单、字典、参数、日志等系统管理能力。

* 采用前后端分离模式：前端 Vue 2 + Element UI，后端 Spring Boot 4 + Spring Cloud & Alibaba。
* 注册中心、配置中心选型 Nacos，权限认证使用 Redis。
* 流量控制框架选型 Sentinel，分布式事务选型 Seata。
* 面向演示与内部展示优化：品牌信息中性化、OA 工作台首页、登录页打磨；演示数据采用 mock + 预留真实接口。

## OA 核心功能

### 办公应用（员工日常办公入口）

1. 待办中心：待我审批 / 我已处理 / 我发起的，优先级标记，点击直达审批。
2. 审批中心：发起请假、报销、出差申请；待我审批 / 我已审批列表；详情页展示**审批流程时间线**（提交 → 部门审批 → 人事审批 → 完成），支持通过/驳回。
3. 会议日程：月历视图 + 当日日程列表，日程事件在日历上标记。
4. 通讯录：组织架构树（复用真实部门接口）+ 人员卡片，支持拨打/发邮件。

### 系统管理（后台管理能力）

5. 用户管理：系统用户配置与维护。
6. 部门管理：组织结构（公司、部门、小组）配置，树结构展示，支持数据权限。
7. 岗位管理：配置系统用户所属职务。
8. 菜单管理：配置系统菜单、操作权限、按钮权限标识。
9. 角色管理：角色菜单权限分配，按机构设置数据范围权限。
10. 字典管理：维护系统中经常使用的固定数据。
11. 参数管理：动态配置系统常用参数。
12. 通知公告：通知公告信息发布与维护（支持已读状态跟踪）。
13. 操作日志：正常/异常操作日志记录与查询。
14. 登录日志：登录日志与登录异常记录查询。

### 系统监控与工具

15. 在线用户：当前系统活跃用户状态监控。
16. 定时任务：在线添加/修改/删除任务调度，包含执行结果日志。
17. 服务监控：监视当前系统 CPU、内存、磁盘、堆栈等信息。
18. 代码生成：前后端代码生成（java、html、xml、sql），支持 CRUD 下载。
19. 系统接口：根据业务代码自动生成 API 接口文档。

## OA 工作台首页

首页即 **OA 工作台**（员工视角门户）：

* 欢迎横幅：当前待办、审批中、本月完成、在线同事统计。
* 快捷入口：发起申请 / 我的待办 / 会议日程 / 通讯录，一键直达对应 OA 页面。
* 今日待办：直接展示待审批单据，点击进入审批详情。
* 今日日程 + 最新公告：会议日程与真实公告数据（`/system/notice/listTop`）。
* 数据图表：近 7 日趋势、协同办公效率、审批类型分布、各部门申请量。

当前业务数据为演示 mock（`ruoyi-ui/src/api/todo.js`、`approval.js`、`calendar.js`、`contacts.js`、`dashboard.js`），真实接口已在各文件以注释预留，接入时无需改页面。
